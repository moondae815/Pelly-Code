# M4 폐쇄망 정보 질문지 (Q9~Q13)

pelly를 폐쇄망에 반입하고 현장에서 검증하려면 아래 정보가 필요합니다. 담당자별로 나눴습니다. 각 표의 「답」 칸을 채워 회신해 주십시오.

* **비밀번호·토큰·개인 계정의 비밀번호는 적지 마십시오.** 주소·버전·설정 값만 적으면 됩니다.
* 모르는 항목은 「모름」이라고 적어 주십시오. 빈칸보다 낫습니다.
* 질문 번호(Q9~Q13)는 PRD §10 「미결 사항」의 번호입니다.

## 1. Ollama 서버 관리자 (Q9·Q10·Q13)

| # | 질문 | 왜 필요한가 | 답 |
| :--- | :--- | :--- | :--- |
| 1-1 | GPU 모델·개수·GPU당 VRAM은 무엇입니까? | 응답 시간 목표(TTFT 1초 미만)를 이 사양에 맞춰 다시 봅니다 (Q9) | |
| 1-2 | 동시에 쓰는 사람은 보통 몇 명, 최대 몇 명입니까? | 동시 요청이 대기하면 작업 시간이 늘어납니다 (Q9) | |
| 1-3 | 서버 환경 변수 `OLLAMA_NUM_PARALLEL`, `OLLAMA_FLASH_ATTENTION`, `OLLAMA_KV_CACHE_TYPE`, `OLLAMA_KEEP_ALIVE`, `OLLAMA_HOST`의 현재 값은? | 권장 값은 `server-checklist.md`에 있습니다. 다르면 결과가 달라질 수 있습니다 (Q9) | |
| 1-4 | Ollama 버전은? (`ollama --version`) | 외부에서 잰 결과와 같은 버전인지 대조합니다 (Q10) | |
| 1-5 | 쓰는 모델 태그는? (`ollama list`의 NAME) | pelly 설정 `llm.model`에 그대로 넣습니다 (Q10) | |
| 1-6 | 그 모델 GGUF 파일의 SHA-256은? 구하는 방법은 `server-checklist.md`의 「모델」 행에 있습니다 | 외부와 같은 모델 파일인지 증명합니다. 버전 기록(`version-record.json`)에 남깁니다 (Q10) | |
| 1-7 | 그 GGUF 파일을 어디서 받았습니까? (파일 이름·출처) 외부에서도 같은 파일을 받을 수 있습니까? | 외부 개발 PC에서 같은 파일로 다시 재기 위해서입니다 (Q10) | |
| 1-8 | 개발 PC에서 서버에 접속하는 주소와 포트는? (예: `http://<서버 이름>:11434`) | pelly 설정 `llm.endpoint`에 넣습니다 (Q13) | |
| 1-9 | 개발 PC와 서버 사이에 사내 프록시가 있습니까? 있으면 개발 PC에서 프록시를 거쳐야 합니까? | pelly는 .NET 기본 프록시 설정(`HTTP_PROXY` 같은 환경 변수, 없으면 Windows 시스템 프록시)을 따릅니다. 거치면 안 되는 경우도 알아야 합니다 (Q13) | |
| 1-10 | 서버 앞에 인증(리버스 프록시, 토큰, 클라이언트 인증서)이 있습니까? | pelly v1은 인증 없는 접속만 지원합니다. 있으면 별도 작업이 필요합니다 (Q13) | |

## 2. 보안·반입 담당자 (Q11)

| # | 질문 | 왜 필요한가 | 답 |
| :--- | :--- | :--- | :--- |
| 2-1 | 바이너리만 반입할 수 있습니까, 소스 코드도 함께 반입해야 합니까? | 반입 묶음 구성을 정합니다. 지금은 바이너리 zip 둘입니다 | |
| 2-2 | 심사에 내야 하는 자료는 무엇입니까? (SBOM, 라이선스 목록, 백신 검사 결과, 해시, 기타) | zip에는 SBOM(CycloneDX)·서드파티 라이선스 목록·SHA-256 목록이 이미 들어 있습니다. 빠진 것을 준비합니다 | |
| 2-3 | 심사는 보통 얼마나 걸립니까? 반입 매체(USB, 전용 망 연계 등)는? | 현장 일정과 재반입 비용을 잡습니다 | |
| 2-4 | 실행 파일 허용 목록(앱 제어)에 등록해야 합니까? 등록 기준은 파일 해시입니까, 서명입니까? | `pelly.exe`, `pelly-eval.exe`는 서명되지 않은 단일 파일입니다 | |
| 2-5 | 사용자 `%TEMP%` 폴더에서 DLL을 불러오는 것이 막혀 있습니까? | `pelly.exe`·`pelly-eval.exe`는 첫 실행 때 SQL 접속용 DLL 하나를 `%TEMP%\.net\` 아래에 풀어 씁니다. 막혀 있으면 풀 위치를 바꾸는 설정(`DOTNET_BUNDLE_EXTRACT_BASE_DIR`)이 필요합니다 (`install.md`) | |
| 2-6 | 폐쇄망 밖으로 비식별 결과를 가지고 나올 수 있습니까? 절차와 허용 형식(텍스트·JSON·Markdown)은? | 현장 결과(`pelly-eval export`, `pelly report --sanitize`)를 가지고 나와야 외부에서 고칠 수 있습니다 | |
| 2-7 | 반출 전 검토자가 따로 있습니까? | 반출 파일 목록을 그 사람에게 맞춰 정리합니다 | |

## 3. 현장 개발 PC 담당자 (Q12)

| # | 질문 | 왜 필요한가 | 답 |
| :--- | :--- | :--- | :--- |
| 3-1 | Windows 버전은? (예: Windows 11 23H2) | 단일 파일 실행과 콘솔 동작을 이 버전 기준으로 봅니다 | |
| 3-2 | 설치된 .NET SDK 버전은? (`dotnet --list-sdks`) | SDK 형식 프로젝트를 빌드·검증하는 데 씁니다 | |
| 3-3 | Visual Studio 또는 Build Tools 버전은? (`vswhere -latest`의 표시 이름) | 레거시 .NET Framework 프로젝트는 MSBuild로 빌드합니다 | |
| 3-4 | 레거시 프로젝트의 .NET Framework 대상 버전과, 설치된 타겟팅 팩은? | 타겟팅 팩이 없으면 빌드 검증이 실패합니다 (`pelly doctor --project`가 확인) | |
| 3-5 | 사내 NuGet 미러가 있습니까? 없으면 패키지는 어떻게 들어옵니까? (로컬 캐시, `packages/` 폴더 커밋 등) | 벤치마크와 판정 테스트는 오프라인으로 복원할 수 있어야 합니다 | |
| 3-6 | 형상 관리 도구는? (git, SVN, TFVC) | pelly는 작업 공간 루트를 `.git`·`.svn`·솔루션 파일로 찾습니다. TFVC면 읽기 전용 파일 처리를 확인해야 합니다 | |
| 3-7 | PowerShell 실행 정책은? (`Get-ExecutionPolicy -List`) | 현장 절차는 cmd·PowerShell 명령을 씁니다. 스크립트 실행이 막혀 있으면 안내를 바꿉니다 | |
| 3-8 | 긴 경로(260자 초과) 지원(`LongPathsEnabled`)이 켜져 있습니까? 소스 폴더의 경로 길이는 대략 얼마입니까? | 벤치마크 작업 복사본은 원래 경로보다 깁니다. 레거시 MSBuild는 긴 경로에서 실패할 수 있습니다 | |
| 3-9 | 테스트 프로젝트는 어떤 프레임워크를 씁니까? (xunit v2, xunit.v3, MSTest, NUnit와 버전) | `pelly cs --test`와 벤치마크 판정이 테스트별 결과를 읽을 수 있는지가 이 종류에 달렸습니다 (`usage.md`) | |
| 3-10 | 개발자 계정에 관리자 권한이 있습니까? | pelly는 관리자 권한 없이 동작하도록 만들었습니다. 확인용입니다 | |

## 4. DB 관리자 (SQL 검증용, Q13 관련)

| # | 질문 | 왜 필요한가 | 답 |
| :--- | :--- | :--- | :--- |
| 4-1 | 개발 DB 서버의 SQL Server 버전은? | 저장 프로시저 문법 검사(NOEXEC 컴파일)의 호환 수준을 맞춥니다 | |
| 4-2 | 개발자가 개발 DB에 Windows 인증으로 접속합니까? | pelly의 기본 연결 방식입니다. 연결 문자열에 비밀번호를 두지 않습니다 | |
| 4-3 | 개발자 계정에 대상 DB의 `VIEW DEFINITION` 권한을 줄 수 있습니까? | pelly는 객체 정의를 읽기만 하고 DB를 바꾸지 않습니다. 이 권한이 최소 권한입니다 | |
| 4-4 | 개발 PC에서 쓰는 서버 이름 형식은? (예: `devdb01`, `devdb01\INST`, `devdb01,1433`) | pelly는 설정의 허용 목록(`sql.allowedHosts`)에 적힌 서버에만 접속합니다. 연결 문자열의 `Server=` 값과 같아야 합니다 | |
